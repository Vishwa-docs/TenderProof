## 1. Show the purchase and purpose — 0:00–0:24

Screen: **Overview**. Show the source, requirement, offer, and acceptance counts.

> TenderProof helps energy contractors review transformer purchases before release. We chose this workflow because equipment commitments cross specifications, supplier offers, and acceptance reports. This real Guam Power Authority package covers three seven-hundred-and-fifty kVA transformers. Apertus eight-B produced thirty-five pending requirements and four offers.

## 2. Find the original unit price — 0:24–0:53

1. Select **Evidence**.
2. Enter `37,105.50` in **Search source text**. Select **Search sources**.
3. Scroll to the first result. Select **Inspect passage** for purchase-order page four.
4. Select **Preview original page 4 of gpa-op34276.pdf**.

> Search connects each claim to its original source. The model placed the three-unit lot total in the unit-price field. Page four shows thirty-seven thousand, one hundred and five dollars, fifty cents per transformer. The saved correction preserves the original output and awaits qualified review.

## 3. Inspect the recorded correction — 0:53–1:10

1. Close the source inspector with its X button.
2. Select **Change history**.
3. Set **From snapshot** to **Revision 11** and **To snapshot** to **Revision 12**.
4. Select **Compare snapshots**. Scroll to show the before/after price values.

> Revision comparison shows exactly which values changed. Each review packet belongs to an exact snapshot. Later content changes invalidate earlier decisions.

## 4. Show the release controls — 1:10–1:25

1. Scroll to the top. Select **Review issues** in the compact status bar.
2. Show the issue list, then close it.

> Review issues identify missing evidence and unresolved extraction checks. This package lacks a completed factory acceptance report. Purchase and shipment remain blocked.

## 5. Export the handoff and explain the business — 1:25–1:55

1. Select **Overview**.
2. Scroll to **Export a review dossier**. Select **Export Markdown**. Keep the download confirmation visible.

> The draft dossier exports sources, claims, corrections, and blockers. We plan on-premise licenses for energy contractors, followed by switchgear and battery procurement. Twenty customers at two hundred fifty thousand dollars annually would produce five million dollars in annual recurring revenue. That is a pricing target. Our next step is an engineering pilot to measure missed obligations and review time.

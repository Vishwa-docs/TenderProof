# Product narrative

TenderProof helps EPC package engineers review transformer procurement evidence before release.
The workbench connects customer requirements, supplier offers, test evidence and controlled decisions.

Apertus proposes structured facts from complete source documents.
Reviewers inspect the cited passages and approve interpretations.
Deterministic checks evaluate encoded constraints and evidence applicability.
The application binds approvals to a package snapshot.
Incomplete extraction blocks purchase and shipment release.

The recorded package contains a real price-basis error.
The model copied a three-unit lot total into a unit-price field.
The pending correction cites the original purchase-order page and preserves the first value.

The next commercial step is a design-partner pilot.
The pilot must measure missed obligations, review time and correction effort.

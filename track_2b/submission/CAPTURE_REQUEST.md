# Recording controls

Use the existing Safari application tab at `http://127.0.0.1:8001`.
Read the exact script in `../../demo.md`.

Allowed recording actions:

- Select a workspace.
- Scroll to an existing row or event.
- Open cited passages and original source-page previews.
- Expand extraction conditions.

Keep extraction, correction, approval and release actions unchanged.
Keep slides outside the recording.
The final video must remain below 120 seconds.
